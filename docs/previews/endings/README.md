# Prévias de cartas de falha

Artes aprovadas e integradas como imagens das cartas de falha. Os originais de revisão ficam aqui; as cópias usadas pelo jogo ficam em `images/endings/` e são referenciadas por `endingImage-*` em `data/interface.json`.

Referência: [fundo marciano existente](../../../assets/images/mars-window.svg). Ilustrações geradas com a ferramenta integrada image_gen, usando a referência de estilo. Paleta roxa/terracota, formas geométricas simples, composição vertical 3:4, símbolo do recurso e textos curtos em inglês. As imagens completas incluem título e explicação. O jogo mantém título e descrição em HTML para leitores de tela e como fallback se uma imagem não carregar. O botão Start New Mission fica fora da imagem.
